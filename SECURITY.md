# Security Policy

SynapseGrid Labs repositories may include experimental AI infrastructure, automation code, and agent workflows. Please report security issues privately.

## Reporting

Email `security@trentdoney.com` with the subject prefix `[SECURITY]`.

Include:

- affected repository
- short vulnerability summary
- reproduction steps or proof of concept
- potential impact
- any suggested mitigation

Do not open public issues for suspected vulnerabilities.

## Scope

Public repositories in this organization are in scope. Private infrastructure, credentials, and internal operational material are not published here and should not be requested through GitHub issues.
