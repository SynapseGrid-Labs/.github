# Contributing

SynapseGrid Labs is Trent Doney's active AI systems practice. Public repositories are maintained as professional release surfaces; private repositories are used for autonomous agent build work.

## Pull Requests

For public repositories:

- describe the change clearly
- include the test or verification performed
- avoid private infrastructure details, secrets, internal hostnames, and incident references
- keep commits descriptive and reviewable
- update documentation when behavior changes

## Commit Messages

Use clear, descriptive commit messages. Conventional Commit prefixes such as `feat:`, `fix:`, `docs:`, `test:`, and `chore:` are encouraged when they make the history easier to scan.

## Agent Contributions

`SynapseOpsAgent` may prepare branches and pull requests. Public-facing changes should include enough verification detail for a human maintainer to review quickly.
